# CFI 精度基线测量结果（cfi-precision-howto 的产出）

测量日期：2026-09-09　工具：`scripts/ikaslr/cfi_precision.py`（+ pyelftools）
方法：W-14（endbr64/BTI 计数）+ W-15（kCFI 等价类，途径 A：DWARF 原型分组）。

## 记录（howto §4 模板）

```
内核版本      ：Linux 6.8（本项目基线）
编译器        ：gcc 11.4（x86）/ aarch64-linux-gnu-gcc 11.4（arm64）
x86 配置      ：x86_64_defconfig + CONFIG_X86_KERNEL_IBT
arm64 配置    ：arm64 defconfig（含 DWARF；ARM64_BTI_KERNEL 未开）
统计口径      ：途径 A（DWARF 原型）——"所有有实体的函数"，口径偏宽
```

## W-14：落地点标记类（IBT / BTI）

| 项 | x86-64 |
| --- | ---: |
| 编译器插入的 endbr64 总数 | 13,322 |
| objtool 封印（`.ibt_endbr_seal`） | 4,415 |
| **剩余 endbr64 = IBT 等价类大小** | **8,907** |

> 注：更大的配置（本项目 build/ 的完整 config）上 IBT 等价类为 **38,180**——
> 等价类大小随内核配置规模变化，报数时须附配置。

arm64：defconfig 未开 `CONFIG_ARM64_BTI_KERNEL`，内核自身无 BTI 落地点
（仅 188 条 bti），改用 PAC-ret（56,952 条 `paciasp`）。故 arm64 的落地点基线不做，
CFI 精度对比以 kCFI 为主。

## W-15：kCFI 等价类分布（途径 A，DWARF，arm64 镜像）

kCFI 按函数**类型签名**分组。类型签名与架构基本无关（同一份 C 源码），故此分布
可代表两个平台。

| 项 | 值 |
| --- | ---: |
| 函数总数（有实体） | 56,470 |
| 不同类型签名数（等价类个数） | 17,883 |
| **最大等价类** | **2,139** |
| 平均等价类 | 3.16 |

最大的几个等价类（长尾）：

| 大小 | 类型签名 |
| ---: | --- |
| 2,139 | `int (*)(void)` |
| 2,069 | `void (*)(void)` |
| 1,266 | `long (*)(struct device*, struct device_attribute*, char*)` |
| 967 | `int (*)(struct device*)` |
| 935 | `int (*)(struct platform_device*)` |

## 表 2-x / 5-x：三类机制精度对比（供第 1.1.4、2.5、5.6.2 节共用）

| 机制 | 等价类划分依据 | 等价类个数 | 最大等价类 | 平均 |
| --- | --- | ---: | ---: | ---: |
| 无 CFI | 无 | 1 | 全部间接可达函数 | — |
| CET-IBT（x86，封印后） | 有无 `endbr64` | 1 | 8,907（defconfig）/ 38,180 | — |
| kCFI | 函数类型哈希 | 17,883 | **2,139** | 3.16 |
| **本文机制** | **调用点唯一上下文** | ≈调用点数 | **1** | **1** |

**结论**：kCFI 的最大等价类达 2,139——决定安全性的正是这个最大值，而非平均 3.16。
本文机制以调用点唯一上下文把非高扇入调用点的等价类降到 1（§5.4/S3.3 已在 arm64
验证：单归属函数定稿为唯一上下文，非 owner 触及即判违规）。高扇入函数移入随机化
区域，不再以等价类衡量（由随机化保护）。

## 口径与局限（如实交代）

- 途径 A 统计"所有有实体的函数"，而 kCFI 等价类只应含**可能被间接调用**的函数，
  分母偏大、等价类偏大。收紧需只统计地址被取过的函数（howto §2.2 注）。
- 途径 B（`__kcfi_typeid_` 符号）更贴近编译器实际划分，但需 `CONFIG_CFI_CLANG`
  （clang ≥16）；本机 clang 14 不支持，故未做。
- 本文机制的"等价类=1"是设计性质（调用点唯一上下文），已在 arm64 机制级验证；
  全内核规模的分布需编译器 PA 插桩（§5.5.1）应用后统计，属 S4.3 后续。
