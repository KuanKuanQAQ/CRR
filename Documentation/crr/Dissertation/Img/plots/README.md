本目录存放**论文实验部分**的插图与其数据源，与 `../schematic/`（机制示意图）分开。

## 结构

- `*.svg`　实验插图，共 14 张，由 `scripts/figs/*.py` 从 `data/` 下的 CSV 生成
- `data/*.csv`　各实验的数据表

## 重新生成

改动 `data/` 下的 CSV 之后，重跑对应脚本即可更新插图：

```sh
python3 scripts/figs/ch3.py     # 图 3-7 至 3-10
python3 scripts/figs/ch456.py   # 图 4-8 至 4-10、图 5-6 至 5-8
python3 scripts/figs/ch6.py     # 图 6-2 至 6-6
```

配色与字体统一在 `scripts/figs/style.py`，沿用 `../reference/drawing-guide.md` 的视觉约定。
输出的 SVG 以 `svg.fonttype='none'` 保存，**文本仍是可编辑文本**。

## ⚠ 数据状态

`data/` 下的数值目前为**预测值**，用于确定图表形式与分析结构，**尚未完成实测**。
各章实验节开头均有「数据状态批注」标明这一点。实测完成后**按同名字段替换 CSV 中的数值、
重跑上述脚本即可**，论文正文表述无需改动。回填完成后记得删除各章的数据状态批注。
