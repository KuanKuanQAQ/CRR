## 生成方式

除第 4 章外的 22 张图（第 1、2、3、5、6 章）已于 2026-09-11 按机制拓扑重绘（三区域带骨架、控制流/数据流线型、图例），改图请改脚本再重跑：

```sh
python3 scripts/figs/fig_ch12.py    # 图 1-1、1-2、2-1 至 2-6
python3 scripts/figs/fig_ch3.py     # 图 3-1、3-2、3-6、3-7、3-8
python3 scripts/figs/fig_ch3pic.py  # 图 3-3、3-4、3-5
python3 scripts/figs/fig_ch4.py     # 图 4-1 至 4-7（未重绘，仍为旧版卡片式）
python3 scripts/figs/fig_ch56.py    # 图 5-1 至 5-5、图 6-1
./scripts/tex/svg2pdf.sh            # 转成 LaTeX 用的 PDF
```

公共的配色、线型、图例与代码块辅助函数在 `scripts/figs/svgbase.py`，与 `../reference/drawing-guide.md` 一致。
视觉契约与无捏造声明见 `visual-composer/visual-contract.md`。
