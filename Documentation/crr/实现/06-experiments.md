# 实验汇总（Phase 4）

本文汇总各章机制级实验（第 3/4/5 章）与第 6 章系统级实验的**已完成结果、可复现
脚本、以及受资源限制的部分及其原因**。

## 环境与口径（贯穿全表）

- 平台：本机 x86-64（QEMU+KVM）；arm64 用 QEMU TCG（`-cpu max`）功能验证。
- **性能数字的关键 caveat**：
  1. **嵌套虚拟化放大约 10 倍**——x86 EPT 路径的 VM exit 被 L0 KVM 拦截模拟，
     VM-exit 密集的绝对开销是悲观值（实测 18326 vs 裸机约 1–2k cyc/exit）。
  2. **arm64 TCG 是纯软件模拟**，绝对时间无参考意义，只验证功能正确性。
  真机（作者的 x86/arm 两台 + KVM）上的数字才是论文最终值。

## 受资源/安全限制、无法在本环境完成的实验（如实声明）

1. **SPEC CPU2006 / LMBench**：需授权软件 / 完整基准环境，本机无。已备触发接口与
   方法，作者在真机 rootfs 中安装后可跑。
2. **Adelie / Dbox 同台对比**：二者可用实现不可得；只能与文献数字对照（实验环境
   不同，说服力打折，须在正文声明）。
3. **真实负载的绝对性能**（网络/存储/端到端开销）：需真机 + KVM + 完整 rootfs；
   本机的 QEMU 数字（尤其 EPT 路径的嵌套虚拟化）不可作为最终值。
4. **真实 CVE 攻击链（E11）**：攻击能力载体已移除，出于安全不再实现。防御机制的
   验证改由内核内自测驱动（读被保护页触发检测等）。
