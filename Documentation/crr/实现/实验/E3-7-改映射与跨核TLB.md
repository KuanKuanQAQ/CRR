# E3-7　改映射与跨核 TLB 失效的代价

| | |
| --- | --- |
| **清单编号** | E3-7（第3章）；【W-38】 |
| **对应正文** | §3.5.5；直接影响 §3.4.6 的分流策略 |
| **状态** | 🟡 **玩具规模**（1 页），但三条结论已明确 |
| **接口** | `/proc/ikaslr/stats` 的 `cp_remap_ns` |

## 1. 目的

陷阱镜像的切换靠**改写页映射**实现，改映射需要使其它核上的 TLB 项失效。回答两个问题：

1. 它在关键路径上值多少时间？
2. 它在**原子上下文**中能不能安全使用？

## 2. 被测机制（§3.5.5 的新实现）

不再"切换后就地填充陷阱指令"，而是：

- **`prepare` 时**（关键路径之外）为每个变体预建一份**陷阱镜像**：与代码区等大的并行
  区域，内容为「每个函数体处填 int3/BRK、其余为 0」，并用 `set_memory_ro/x` 置 RO+X
  （连同直映射别名，避免跨别名 W+X）。
- **退役时**只把代码区的页表项**重指**到陷阱镜像的物理页
  （`apply_to_existing_page_range` 改 pfn，不改权限）+ 一次 `flush_tlb_kernel_range`。

## 3. 步骤

```sh
# 启动后读 /proc/ikaslr/stats，触发 200 轮后再读
cat /proc/ikaslr/stats        # 看 cp_remap_ns
```

## 4. 结果

### 结论一：改映射是 **µs 级**，不是 ns 级

```
cp_remap_ns = 28 486 ns ≈ 28.5 µs
```

是关键路径其余部分（`cp_wait` 204 ns + `cp_update` 271 ns = 475 ns）的 **60 倍**。
开销来自 `apply_to_existing_page_range` 遍历页表 + `flush_tlb_kernel_range` 的跨核 IPI。

QEMU 的 IPI 比真机贵，真机预计**单位数 µs**，但**量级仍是 µs**。
且当前变体只有 **1 页**；范围扩大后页数增加，改映射耗时会随之上升。

### 结论二：暴露窗口**并未消除**（修正先前说法）

实际执行顺序：

```c
ikaslr_live = next;  spin_unlock(...);
ikaslr_unblock_region();               /* ← 区域重新开放 */
WRITE_ONCE(ikaslr_last_ns, ...);       /* ← 关键路径计时到此为止 */
if (old && preemptible())
        ikaslr_retire_trap(old);       /* ← 改映射在这之后才发生 */
```

**改映射发生在 `unblock` 之后**。因此从 unblock 到 remap 完成之间（约 28.5 µs）：
区域已开放、**旧变体仍是有效可执行的旧代码**、陈旧返回不会陷入。

> 先前「预建镜像 + 改映射使窗口即刻关死」的说法**不成立**。
> 改映射只是把窗口从「填充耗时」缩短到「改映射耗时」，**没有消除它**。

**两条可选处置（需作者定夺）**：

| 方案 | 效果 | 代价 |
| --- | --- | --- |
| 把 `retire_trap` 移到 `unblock` **之前** | 窗口期间区域仍被阻断 | 区域多阻断约 28.5 µs；且**仍不能完全消除**——TLB 刷新完成前其它核可能仍用旧 TLB 项执行旧代码 |
| **接受该窗口**，正文如实写明其长度（µs 级） | 实现不变 | 需论证该窗口的可利用性极低 |

### 结论三：原子上下文**不可用**

`flush_tlb_kernel_range` 经 `on_each_cpu`／`smp_call_function` 发 IPI，**要求本地中断开启**。
关中断上下文调用会触发告警并有死锁风险。

实现文档已记录同类事故：`set_memory_*` 的跨核 TLB flush 在**关中断且持有 VMCS**
的上下文里破坏系统状态（随后 init 段错误）。改映射有同样的约束。

## 5. 判据与后续（清单要求给出明确结论）

> **§3.4.6 的「就地完成」条件必须收紧为：仅在可抢占上下文。**
> 原子上下文中随机化必须整体推迟。

当前实现的 `if (old && preemptible())` 守卫与此一致，但**正文需要把这条约束写明**，
而不是含糊带过。

## 7. 局限

- 变体只有 **1 页**（3 个示例函数）。改映射耗时随页数增长，范围扩大后必须重测。
- QEMU 的 IPI 成本高于真机，28.5 µs 应视为**悲观上界**。
