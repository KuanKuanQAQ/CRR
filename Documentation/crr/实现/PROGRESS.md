## 平台与关键决策（来自论文 R-61/R-64/R-67，已与作者确认）

- **两套物理机都有**：x86-64 一台、ARM64（支持 FEAT_PAuth + 调试观察点）一台。计划在**各自架构的 QEMU+KVM** 上跑功能与性能测试（因 KVM 不跨架构，故两台分别跑）。
- **主平台 = ARM**（第5章 PA、第4章观察点路径）；**x86 验证第3、4章可移植性**（第4章走 EPT 路径）。
- **LLVM pass 策略**：先做内核运行时，用现有「手工注解 + `.rand.text`/`.tramp.text` 段」路径实现（当下可编译可测），**LLVM pass 的职责写成明确接口 + 桩，留作后续步骤**。
- **待定项 D-EPT**：x86 下 EPT 施加 XOM 的部署模型（嵌套 EPT vs 宿主 KVM 侧强制）—— 见 [`04-detection.md`](./04-detection.md)，先把运行时写成平台无关。
