# arm64 平台使能（Chapter 4 观察点 / Chapter 5 PA CFI 的前提）

第 5 章 PA CFI 与第 4 章观察点路径都需要 arm64。本文记录让 arm64 内核带 IKASLR
编译并启动所做的工作。**本机（x86）用 QEMU TCG 做功能验证；性能须在 arm64 真机上
测（作者的 ARM 机 + KVM）。**

## 链接脚本 wiring

x86 的 IKASLR 段宏原名 `TRAMP_TEXT`/`RAND_TEXT`，**与 arm64 自有的 `TRAMP_TEXT`
（KPTI 入口跳板 `.entry.tramp.text`）冲突**。已改名为 `IKASLR_TRAMP_TEXT` /
`IKASLR_RAND_TEXT`（`include/asm-generic/vmlinux.lds.h`），段名与边界符号不变。

arm64 `vmlinux.lds.S`：
- `.text` 段内、`_etext` 之前插入 `IKASLR_TRAMP_TEXT` / `IKASLR_RAND_TEXT`（页对齐）；
- 新增 `.data..ikaslr` 段放 `TRAMP_TABLE_DATA` / `RAND_TABLE_DATA` / `IKASLR_TABLE_DATA`。

## 陷阱机制：arm64 用 BRK + 内核 break hook（不是 UDF）

方案 B 的兜底要把退役变体/被探测函数填成"陷阱指令"，执行到即被截获并重定向 PC。
每架构用其**干净的软件断点**：

| 平台 | 陷阱 | 截获路径 |
| --- | --- | --- |
| x86-64 | `int3`（0xCC） | die notifier 的 `DIE_INT3`，可干净恢复 |
| arm64 | `BRK #0x462` | `register_kernel_break_hook`，返回 `DBG_HOOK_HANDLED` |

**为什么 arm64 不用 UDF+die notifier**：arm64 的未定义指令走 `do_el1_undef → die()`。
即使 die notifier 返回 `NOTIFY_STOP` 能跳过 `make_task_dead`（`traps.c:237`）从而恢复，
`die()` 仍会每次打印 `Internal error: Oops - Undefined instruction` 并 `add_taint`。
对一个在每次陈旧返回都触发的机制这不可接受。而且早期实现的字符串匹配
`"undefined instruction"` 还匹配不上 arm64 的 `"Oops - Undefined instruction"`（大小写）。

`BRK` 经内核 break hook 是 x86 `int3` 的正确对应物：干净、无 oops、无污染。陷阱填充
由 `ikaslr_fill_traps()` 按架构生成（x86 填 0xCC 字节；arm64 填 4 字节 `brk` 指令字）。
BRK 立即数取 `0x462`，避开内核已用的（kprobes/kgdb/bug/kasan/cfi 等）。

## 验证（QEMU TCG，`-cpu max`，单核）

Phase 1 全部机制 + 控制流审计在 arm64 上通过：

```
ikaslr: stale-return fixup armed (brk #0x462)
ikaslr/selftest: stale: called retired ... got 42 (fixups 0->1)   ← BRK 兜底触发
ikaslr/selftest: audit: PASS - entry=benign, middle=gadget+trigger
ikaslr/selftest: PASS: dispatch + tracking + block + rerand + defer + fixed_out + stale-return
SMOKE: PASS
```

一般函数迁移（randfuncs.c，用 x86 `-mcmodel=large`）在 arm64 上暂不编译——arm64 的
外部调用是 PC 相对 `bl`，需编译器插件改为经 GOT 的间接跳转（见 `03-randomization.md`
的架构差异一节）。该自测已用 `#if CONFIG_X86_64` 守卫。

## 复现

```sh
mkdir build-arm64
make O=build-arm64 ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- defconfig
./scripts/config --file build-arm64/.config --enable IKASLR --enable IKASLR_DEBUG --enable IKASLR_STATS
make O=build-arm64 ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- olddefconfig
make O=build-arm64 ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- CRR_TRAMPOLINE=n -j$(nproc)
scripts/ikaslr/boot-arm64-smoke.sh build-arm64
```
